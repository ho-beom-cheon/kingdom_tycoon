# CSV 데이터

UTF-8 BOM으로 저장한다. ID는 고유해야 하며 참조 필드는 존재하는 ID를 가리켜야 한다.

- `jobs.csv`: 직업
- `skills.csv`: 스킬
- `traits.csv`: 능력 특성
- `personalities.csv`: 구매·위험 성향
- `status_effects.csv`: 상태 효과
- `grades.csv`: 기본 등급
- `ranks.csv`: 성장 랭크
- `promotion_grade_requirements.csv`: 고등급 추가 승급 재료
- `kingdom_stages.csv`: 왕국 단계
- `regions.csv`: 지역
- `monsters.csv`: 몬스터·레이드 보스
- `raids.csv`: 레이드 규칙
- `raid_parts.csv`: 보스 부위
- `materials.csv`: 재료·소모품·증표
- `loot_entries.csv`: 드롭
- `equipment_templates.csv`: 장비 템플릿
- `equipment_quality.csv`: 품질
- `recipes.csv`: 제작법
- `potions.csv`: 포션
- `facilities.csv`: 시설 레벨
- `npc_professions.csv`: 관리 NPC
- `npc_proficiency.csv`: 숙련도
- `enhancement_rules.csv`: 강화
- `refine_options.csv`: 제련 옵션
- `recruitment_pools.csv`: 모집 확률
- `recruitment_pity.csv`: 천장
- `balance_parameters.csv`: 공통 조정값
- `localization_ko.csv`: 핵심 문자열
- `asset_register.csv`: 에셋 라이선스 등록 템플릿
