# 코어 런타임 성능 안정화 완결성 검토 v1.1

## 검토 결과

구현 진행 가능. 실측된 1MB Save의 대형 저널을 삭제하거나 축약하지 않고도 읽기 경로와 임시 상태 반영의 중복 복제를 제거할 수 있다.

## 완결성 체크

- [x] 장기 Save 크기와 주요 점유 경로를 실측했다.
- [x] 읽기 전용 현재 문서 참조와 mutation draft 소유권을 구분했다.
- [x] 디스크 저장·검증·백업의 방어적 복제는 유지한다.
- [x] `operationJournal` 보존과 멱등 재생 계약을 유지한다.
- [x] 입력 중 계산 양보와 재개 조건이 정의되어 있다.
- [x] 활성·비활성 지역 모션 빈도와 시각 품질 보존 조건이 정의되어 있다.
- [x] 불필요한 uGUI 색상 쓰기 제거 범위가 정의되어 있다.
- [x] 기존 Profiler marker와 전체 회귀 검증 범위가 유지된다.

## 기존 설계와의 충돌 검토

- Save schema, `saveVersion`, `contentVersion`, revision과 checksum 규칙에 변경이 없다.
- 원자 저장, 임시 파일 검증, 3세대 백업과 복구 순서에 변경이 없다.
- 자동 사냥의 배치·전투·전리품·귀환·판매·성장 결정론에 변경이 없다.
- v1.0의 20초 병합 저장과 프레임당 상태 전이 예산을 유지한다.
- 모바일 통합 월드의 카메라 구도, 건물·캐릭터 상호작용과 에셋을 유지한다.

## 위험과 대응

- 소유권 이전 뒤 caller가 draft를 다시 변경하면 현재 상태가 변할 수 있다. 호출 지점을 자동 사냥 서비스 하나로 제한하고 반영 뒤에는 읽기만 수행한다.
- 낮은 빈도의 비활성 지역 모션이 덜 부드럽게 보일 수 있다. 배치 또는 선택 즉시 24Hz로 복귀하고 캐릭터·전투 피드백은 유지한다.
- 입력이 계속 유지되면 시뮬레이션 적용이 늦어진다. 입력 종료 150ms 후 기존 예산으로 재개하며 시뮬레이션 시각 자체는 삭제하지 않는다.

## 미해결 항목

`operationJournal` 자체의 장기 보존·pruning 정책은 Save 멱등 계약 변경이므로 이번 구현에서 제외한다. 별도 설계 없이 과거 행을 삭제하지 않는다.
