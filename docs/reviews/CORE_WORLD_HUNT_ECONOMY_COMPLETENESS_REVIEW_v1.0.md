## 기존 설계와의 합치

- 일반 전투 자동화 원칙과 30초 사냥·5분 귀환 경제 루프를 유지한다.
- `regions.csv`, `monsters.csv`, `loot_entries.csv`, 상점·장비 CSV를 재정의하지 않는다.
- 레이드 보스는 일반 필드에서 제외하므로 P14 레이드 흐름과 충돌하지 않는다.
- Presenter가 Save를 직접 변경하지 않고 Application/Infrastructure 서비스만 호출한다.
- 무료·런타임 도형 기반 화면을 사용하므로 향후 에셋 교체 전에 동작 완성도를 검증할 수 있다.

## 구현 전 결정 완료 목록

- 월드 좌표와 재생성 시간: 별도 튜닝 JSON
- 몬스터 수: 지역당 5 슬롯 기본값
- 동시 공격: 빈 목표 우선, 부족하면 합류
- 드롭 난수: Save 식별자 기반 결정적 해시
- 장비 드롭: 지역 티어+용병 직업 적합 템플릿, 보통 품질
- 상점 미운영: 전리품 보존, 사냥 재개
- 수동 실행: 이번 요청에서 제외, 자동 검증은 유지

추가 설계 요청 없이 구현을 진행한다.
