## 1. 결론

설계는 참고작에서 가져올 관찰형 타이쿤 원칙과 복제 금지 경계를 분리했고, 투영식·월드 좌표·도로 연결·건물 기능·캐릭터 상세 정보 권위·반응형·오류 상태·Save 불변·테스트 기준을 단일 해석으로 고정했다. 추가 상세 설계 없이 구현할 수 있다.

## 2. 요구사항 완결성

| 요구사항 | 설계 결정 | 판정 |
|---|---|---|
| 참고작과 같은 방향의 카메라 | 오른쪽 위에서 내려다보는 사선형 탑다운 투영 | `PASS` |
| 왕국과 사냥터의 자연스러운 연결 | 환형 지역 좌표, 4개 관문, 3층 도로 | `PASS` |
| 건물 기능 진입 | 시설별 1차·보조 기능을 기존 내비게이션에 매핑 | `PASS` |
| 캐릭터 클릭 상세 | 실제 Mercenary/ContinuousHunt DTO를 결합한 모달 | `PASS` |
| 장비 확인·변경 | 실제 4개 슬롯 표시, 기존 가방 화면 진입 | `PASS` |
| 캐릭터·몬스터·건물 품질 | 공통 외곽선·광원·그림자와 시설 5종 고유 자산 | `PASS` |
| 게임 같은 밀도 | 지역 카드 제거, 불규칙 지형, 광장·성벽·관문·장식 | `PASS` |

## 3. 지식재산권 검토

| 항목 | 결정 | 판정 |
|---|---|---|
| 참고 화면 | 정보 구조와 관찰성만 분석 | `PASS` |
| 타사 이미지 | 런타임·문서 자산으로 반입하지 않음 | `PASS` |
| 타사 명칭·수치 | 사용하지 않음 | `PASS` |
| UI 프레임 | 청록·석재·황동 기반 독자 구성 | `PASS` |
| 픽셀 자산 | 기존 내부 생성 자산과 등록된 CC0만 사용 | `PASS` |

참고작의 공식 자료는 기능 관계 검증에만 사용한다. 결과 화면은 동일한 좌표, 프레임 장식, 캐릭터·건물 실루엣을 재현하지 않는다.

| 계층 | 변경 | 금지 | 판정 |

| `ContinuousHuntGameService` | 없음 | View 좌표·선택 상태 저장 | `PASS` |

캐릭터 상세의 전투 지표는 이미 존재하는 최근 피해·스킬 합계·최고 강화·순환·수익만 표시한다. 공격력·방어력 등 현재 DTO에 없는 수치를 임의 계산하지 않는다.

## 5. 화면·입력 완결성

- 사선 투영은 논리 좌표를 바꾸지 않고 모든 View 목적지에 동일하게 적용한다.
- 시설·용병·사냥터 탭은 동일한 드래그 억제 규칙을 사용한다.
- 시설 패널, 배치 시트, 메뉴, 캐릭터 모달은 동시에 하나만 열린다.
- 캐릭터 모달은 스크림과 닫기 버튼을 모두 제공한다.
- 장비 변경은 기존 가방 화면으로 이동하므로 새 장착 명령이 필요 없다.
- 세로·장화면·가로 폴백 치수와 최소 터치 영역이 수치로 고정됐다.

판정: `PASS`

## 6. 상태·오류 완결성

Loading, Content, Empty, Error, Locked, Offline 상태의 표시와 다음 행동이 정의됐다. 외부 타일 누락, 상세 대상 소실, 서비스 오류, 드래그 뒤 오입력도 복구 동작이 있다.

판정: `PASS`
