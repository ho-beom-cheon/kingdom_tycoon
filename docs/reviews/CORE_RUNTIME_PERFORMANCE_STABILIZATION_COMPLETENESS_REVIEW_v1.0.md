# 코어 런타임 성능 안정화 완결성 검토 v1.0

## 검토 결과

구현 진행 가능. 저장 복구 계약과 게임 규칙을 유지하면서 병목을 제거할 수 있다.

## 계약 검토

- [x] 자동 사냥 계산과 디스크 저장 책임이 분리되어 있다.
- [x] 기존 원자적 저장·백업·검증 계약이 유지된다.
- [x] 명시적 경제 거래의 즉시 저장 권한이 유지된다.
- [x] 앱 일시정지·종료 시 flush 조건이 정의되어 있다.
- [x] 프레임당 상태 전이 예산과 화면 발행 빈도가 정의되어 있다.
- [x] 입력 우선순위와 유휴 저장 조건이 정의되어 있다.
- [x] 화면 품질과 월드 배치 보존 조건이 정의되어 있다.
- [x] Canvas 격리와 변경값 기반 갱신 전략이 정의되어 있다.
- [x] EditMode·PlayMode 회귀 검증 항목이 정의되어 있다.

## 기존 설계와의 충돌

- `docs/18_SAVE_OFFLINE_PROGRESS.md`의 원자적 저장과 3세대 백업을 유지한다.
- `docs/20_UNITY_ARCHITECTURE.md`의 이벤트 기반 UI 갱신 원칙을 강화한다.
- `docs/24_PERFORMANCE_TARGETS.md`의 전체 UI 재빌드 금지와 프레임 예산을 구현한다.
- Save schema, `saveVersion`, `contentVersion`, 게임 밸런스 데이터에는 변경이 없다.

## 위험과 대응

- 강제 종료 시 최대 20초의 일반 자동 사냥 진행이 유실될 수 있다. 앱 일시정지·종료 flush와 명시적 거래 저장으로 제한한다.
- 중첩 Canvas가 정렬이나 입력을 바꿀 수 있다. PlayMode에서 지역·건물·용병 클릭과 표시 순서를 검증한다.
- 누적 진행 분할로 화면 반영이 늦어질 수 있다. 계산을 짧은 간격으로 이어가고 화면 발행을 최대 5 Hz로 제한한다.

## 미해결 항목

없음. 전체 월드를 Tilemap/SpriteRenderer로 교체하는 작업은 현재 성능 기준을 달성하지 못할 경우의 후속 렌더러 전환이며, 이번 안정화의 완료를 막는 선행 조건이 아니다.
