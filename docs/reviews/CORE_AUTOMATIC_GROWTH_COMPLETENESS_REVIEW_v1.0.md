## 충돌 해소

- P10의 사용자 수동 강화는 장착 해제 장비만 허용한다. 이번 자동 정비는 마을에 귀환한 용병이 자기 장착 장비만 다루는 별도 시스템 행위로 한정해 충돌을 해소한다.
- 확률 강화는 상용 게임에서 중요한 선택이므로 자동 정책은 성공률 100%인 +5까지만 사용한다.
- 스킬별 독자 레벨 표가 없으므로 콘텐츠에 이미 존재하는 해금 스킬을 공통 3레벨 성장으로 정의한다. 이후 밸런싱은 정책 데이터만 교체할 수 있다.
- 자원 부족은 오류가 아니라 `건너뜀` 결과이며 사냥 자동 복귀를 보장한다.

## 구현 전 위험 점검

- Save 스키마에 새 상태와 필드를 먼저 추가하고 이전 골든 문서를 재생성한다.
- 콘텐츠 CSV를 복제하지 않고 활성 카탈로그를 읽어 드리프트를 방지한다.
- 성장 효과는 정수 BPS로 계산해 플랫폼별 부동소수점 차이를 막는다.
- UI는 기존 3열 구조 내부에서 텍스트만 확장하고 최소 터치 영역을 유지한다.
