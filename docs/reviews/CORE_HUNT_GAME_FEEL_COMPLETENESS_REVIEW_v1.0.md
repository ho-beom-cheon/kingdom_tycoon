## 기존 계약과의 합치

- `ContinuousHuntGameService`가 커밋한 DTO만 관찰하므로 View가 Save를 직접 변경하지 않는다.
- 전투 피해, 드롭 확률, 귀환, 상점·성장 순서를 변경하지 않는다.
- Save와 콘텐츠 스키마 버전을 올리지 않는다.
- 외부 에셋이 없어 `asset_register.csv` 변경과 구매 승인이 필요하지 않다.
- 효과음 없이도 텍스트·숫자·색상·형태로 모든 핵심 상태를 확인할 수 있다.
- 모션 감소 모드는 게임 시간이나 자동 사냥 속도를 변경하지 않는다.

## 구현 전 결정 완료 목록

- 표현 이벤트 원천: 직전/현재 조회 DTO 차이
- 중복 방지: 첫 관찰 무시 + 리비전 단위 처리
- 피드 수: 3행 고정 재사용
- 위험도: 지역 티어의 한국어 5단계
- 대표 드롭: 지역 encounter의 loot 합집합에서 최대 2개
- 음향: 화면 로컬 4종 절차형 AudioClip 캐시
- 설정 저장: PlayerPrefs, 게임 Save 제외
- 수동 실행: 제외

추가 상세 설계 요청 없이 구현을 진행한다.
