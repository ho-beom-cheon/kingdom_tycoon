# 상시 자동 사냥 핵심 루프 정정 설계 완결성 검토 v1.0

## 결론

## 기존 설계와의 정정 관계

- P06의 `StartHuntCommand`와 단일 `RuntimeSession`은 레거시 호환 및 파티 전투에 남긴다.
- 일반 사냥터 내비게이션은 `ContinuousHuntGameService`와 상시 사냥 화면을 사용한다.
- P12 지역 화면은 지역 해금·파견 정책 생명주기를 유지하며 상시 사냥 화면 뒤에서 호환된다.
- P15 오프라인 계약은 장시간 정산 상한을 계속 담당하고, 짧은 경과는 용병별 `nextDecisionAtUtc` catch-up이 담당한다.

## 의도적으로 남긴 범위

- 스킬 소유/레벨 Save 계약이 아직 없으므로 자동 스킬 구매는 다음 성장 계약에서 다룬다.
- 유료 에셋은 상용화 판단 뒤 도입한다.
- 현재 도형 기반 동작은 게임 루프 검증용이며 에셋 교체가 상태 머신을 변경하지 않는다.
