## 1. 결론

설계는 구현에 필요한 제품 목표, 화면 방향, 월드 좌표, 입력 경계, 상태-목적지 매핑, 복수 배치 명령, 기존 화면 연결, 외부 에셋 라이선스, Save 비변경, 성능 예산, 오류 복구와 자동 테스트를 모두 단일 해석으로 고정했다. 구현을 막는 누락이나 상충 결정은 없다.

## 4. 상태·흐름 완결성

### 4.1 용병 상태

기존 14개 상태 모두 왕국 시설, 길, 사냥터 중 하나의 유효 목적지를 갖는다. 알 수 없는 상태는 왕국 광장으로 복구한다. 상태 전환 중 위치는 표현 보간이며 저장 대상이 아니다. `PASS`.

### 4.2 몬스터 상태

`ACTIVE`와 `RESPAWNING`의 위치·가시성·피드백이 정의돼 있다. 실제 HP·표적·사망·재생성은 기존 Save와 서비스가 권위다. `PASS`.

### 4.3 플레이어 입력

드래그, 탭, 핀치, 왕국 복귀, 시트 열기·닫기, 배치·해제가 정의돼 있다. 드래그-클릭 경합은 누적 이동 기준과 클릭 소비 규칙으로 해소했다. `PASS`.

### 4.4 화면 연결

첫 생활 월드, 우측 상단 통합 메뉴, 기존 전체 화면 열기, 왕국 복귀 경로가 정의돼 있다. 하단 고정 내비게이션은 숨기되 기존 Presenter는 제거하지 않는다. `PASS`.

## 5. 데이터·Save 완결성

- Save 스키마 추가 없음
- Migration 추가 없음
- 콘텐츠 버전 증가 없음
- 카메라·표현 좌표 비저장
- 기존 지역·시설·용병·몬스터 ID 재사용
- 배치 명령은 기존 서비스 공개 API 재사용

따라서 기존 Save는 정규화나 변환 없이 동작한다. `PASS`.
