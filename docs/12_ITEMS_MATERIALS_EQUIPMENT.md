# 재료·아이템·장비

## 재료 원칙

- 이름만 다른 상위 재료 반복을 최소화한다.
- 지역, 몬스터, 부위, 속성의 정체성을 갖는다.
- 대부분의 재료는 최소 2개 시스템에서 사용한다.
- 단일 제작법 전용 재료는 보스·서사적 희귀품에 한정한다.

## 장비 구조

### 슬롯

- 무기
- 방어구
- 투구
- 장신구

### Tier

T1~T5. 획득 지역과 기본 능력 규모를 나타낸다.

### 품질

- 일반
- 정교
- 희귀
- 유산
- 유물

품질은 기본 배율과 선천 옵션 확률을 결정한다. 용병 기본 등급·성장 랭크와 시각 언어를 분리한다.

## 획득

- 일반 장비: 제작 중심 + 낮은 확률 완제품 드롭
- 희귀 장비: 제작·정예 드롭
- 보스 장비: 부위 재료 제작 중심
- 유물: 최종 레이드·도감·고난도

## 자동 처리

새 장비 획득 시:

1. 직업 착용 가능 여부
2. 현재 장비와 점수 비교
3. 희귀 보호 정책
4. 자동 착용 또는 보관·판매

## 중복·낮은 장비

- 분해하여 강화석
- 제작 연구 실적
- 도감
- 판매
- 강화 투자 재료 일부 환급

## 도감

1.0 최소 정보:

- 발견 여부
- 획득 지역·몬스터
- 제작법
- 최고 품질
- 최초 획득 용병
- 누적 획득량
