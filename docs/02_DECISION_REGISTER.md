# 결정 등록부

## CONFIRMED

- 판타지 왕국 재건 타이쿤.
- 스토리는 최소한으로 유지한다.
- 핵심 재미는 재료와 장비 수집이다.
- 용병은 자율적으로 사냥, 귀환, 판매, 구매, 포션 사용, 장비 교체를 수행한다.
- 용병 기본 등급: C/B/A/S/SS.
- 용병 성장 랭크: 수습/정식/숙련/정예/영웅/전설.
- 주점 모집은 C~A만 제공한다.
- 특별 모집은 A~SS를 제공한다.
- 특별 모집 수단은 특별 모집권, 무료·유료 프리미엄 재화다.
- 특정 직업 확률 상승 모집 이벤트를 지원한다.
- 고등급은 최종 잠재력이 높지만 승급 비용과 특정 재료 요구가 크다.
- 지역은 왕국 단계, 몬스터 토벌, 레이드 성공으로 개방한다.
- 지역 출입은 용병 성장 랭크로 제한한다.
- 생산 NPC는 용병의 실제 이용·작업량으로 숙련도가 오른다.
- 시설 건설 권한과 담당 NPC 고용 후보는 같은 시점에 개방한다.
- 시설 건설 + NPC 배치 후 가동한다.
- 강화와 기본 제련을 1.0에 포함한다.
- 펫은 후속 업데이트다.
- Unity를 사용한다.
- Git을 사용한다.
- PostgreSQL을 사용한다.
- 서버·DB 구현은 `docs/design/TYCOON_DB_INTERFACE_DESIGN_v1.0.md`를
  상세 기준선으로 사용한다.
- DB 작업은 해당 문서의 P0/P1/P2 트랙으로 나누어 검증하며, Unity 중심의
  P02~P15 순서를 임의로 완료 처리하지 않는다.
- DB P0 후보는 이슈 #10에서 감사·보강 후 채택하고, P1/P2는 별도 이슈와
  새 Flyway migration으로 진행한다.
- IntelliJ IDEA를 서버 개발 도구로 사용한다.
- 초기 에셋은 무료 중심, 유료 총예산은 200,000원 이하.
- 서버 배포 등 운영 항목은 개발 완료 후 하나씩 결정한다.
