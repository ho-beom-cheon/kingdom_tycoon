# 1.0 범위

## 목표

신규 플레이어가 폐허 전초기지에서 시작해 왕국 5단계를 완성하고 최종 레이드 `잿빛 고룡`을 최초 토벌한 뒤 반복 고난도 콘텐츠에 진입할 수 있어야 한다.

## 콘텐츠 규모

| 항목 | 1.0 기준 |
|---|---:|
| 직업 | 5 |
| 일반 지역 | 5 |
| 레이드 | 2 |
| 일반·정예 몬스터 | 25 |
| 활동 용병 | 시작 4, 최대 16 |
| 총 보유 용병 | 최대 24 |
| 핵심 시설 | 8 |
| 관리 NPC 직종 | 4 |
| 성장 랭크 | 6 |
| 장비 슬롯 | 4 |
| 장비 Tier | 5 |
| 장비 품질 | 5 |
| 강화 | +10 |
| 제련 옵션 | 장비당 1개 |

## 1.0 포함

- 일반 사냥 자동 전투
- 용병 개인 골드
- 장비·재료 획득, 자동 착용, 판매
- 상점 구매
- 포션 생산·구매·자동 사용
- 시설 건설·업그레이드
- 생산 NPC 고용·숙련
- 용병 모집·승급
- 지역 개방·출입 제한
- 장비 제작·강화·제련·분해
- 레이드 준비·자동 전투·결과
- 로컬 저장·오프라인 정산
- 상시 특별 모집 UI와 서버 교체 가능한 Mock
- 도감 최소 기능
