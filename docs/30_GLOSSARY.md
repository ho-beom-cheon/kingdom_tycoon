# 용어집

- 기본 등급: C~SS, 태생 잠재력
- 성장 랭크: 수습~전설, 플레이 경력·콘텐츠 접근
- Tier: 장비·지역의 세대와 기본 능력 규모
- 품질: 일반~유물, 같은 Tier 안의 완성도
- 개인 골드: 용병이 직접 소비
- 왕국 골드: 플레이어가 시설에 사용
- 관리 NPC: 고용·배치·숙련 가능한 비전투 인력
- 시스템 NPC: 기능만 제공하는 고정·방문 인물
- 제련: 장비 옵션 변경
- 강화: 장비 기본 수치 증가
- 활동 용병: 실제 월드·사냥에 투입 가능한 용병
- 보유 용병: 활동·비활동 포함 전체
- 왕국 단계: 거점 발전 단계, 시대가 아님
