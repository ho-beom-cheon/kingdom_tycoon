# 기본 등급·성장 랭크·승급

## 기본 등급

```text
C → B → A → S → SS
```

기본 등급은 모집 희귀도와 잠재력을 나타내며 원칙적으로 변경되지 않는다.

- C~A: 주점 가능
- A~SS: 특별 모집 가능
- 모든 등급은 전설 랭크까지 성장 가능
- C 대비 SS의 완성 능력 차이는 장비를 제외하고 약 15~20% 범위
- 고등급은 승급 비용과 전용 재료 요구가 높음

## 성장 랭크

```text
수습 → 정식 → 숙련 → 정예 → 영웅 → 전설
```

랭크는 경력, 레벨 상한, 스킬, 지역 출입, 레이드 자격을 나타낸다.

## 승급 처리

```text
현재 랭크 최대 레벨
+ 활동 기여도
+ 전투 실적
+ 개인 골드
+ 승급 증표
+ 왕국 지원 재료
→ 모험가 길드 심사
→ 일정 시간 후 승급
→ 레벨 1 초기화
→ 장비·개인 골드·특성 유지
```

## 고등급 비용

기본 비용 배율:

- C 1.00
- B 1.10
- A 1.25
- S 1.50
- SS 1.80

S·SS는 정예→영웅, 영웅→전설에서 전용 각성 재료가 필요하다.

## 랭크 의미

- 수습: 초급 지역
- 정식: 일반 지역
- 숙련: 위험 지역·중급 던전
- 정예: 정예 지역
- 영웅: 레이드·최상위 일반 지역
- 전설: 최종 레이드·고난도 변종
