# 핵심 루프와 진행

## 30초 루프

```text
용병이 몬스터 탐색
→ 자동 전투
→ 골드·재료·장비 획득
→ 체력·포션·인벤토리 판단
→ 계속 사냥 또는 귀환
```

## 5분 루프

```text
귀환
→ 재료·불필요 장비 판매
→ 치료·포션·장비 구매
→ 생산 시설 재고 변화
→ 더 적합한 사냥터로 출발
```

## 30~60분 루프

```text
재료 축적
→ 제작·강화·제련
→ 시설 업그레이드
→ 용병 승급
→ 신규 지역·레이드 개방
```

## 장기 루프

```text
왕국 단계 상승
→ 상위 Tier 재료·장비
→ 영웅·전설 용병
→ 왕국 완성
→ 최종 레이드 최초 토벌
→ 고난도 변종과 장비 완성
```

## 왕국 단계

1. 폐허 전초기지
2. 정착 마을
3. 요새 도시
4. 성채 수도
5. 복구된 왕국

단계는 시대 변화가 아니며 같은 세계 안에서 거점이 성장하는 표현이다.

## 최종 레이드 이후

- 최종 레이드는 계속 반복 가능하다.
- 난이도 단계와 주간 변형을 제공한다.
- 신규 시대·대륙을 자동 개방하지 않는다.
- 최종 진행은 장비 품질, 강화, 제련, 도감, 변종 보스로 이어진다.
