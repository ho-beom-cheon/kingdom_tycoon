# 튜토리얼·온보딩

## 원칙

- 긴 설명 대신 행동 기반.
- 한 번에 하나의 시스템만 개방.
- 강제 손가락 애니메이션은 최소화.
- 이미 아는 플레이어는 빠르게 넘길 수 있음.

## 20~30분 흐름

1. 폐허 전초기지 확인
2. 주점에서 첫 C/B 용병 모집
3. 외곽 초원 출입 허가
4. 자동 사냥 관찰
5. 귀환·판매
6. 대장간 개방 및 기본 무기 제작
7. 용병이 장비 구매·착용
8. 연금술 공방 개방, 하급 포션 생산
9. 수습 최대 레벨·정식 승급 체험
10. 어둠숲 개방

## 가르칠 순서

```text
사냥
→ 귀환
→ 판매
→ 구매
→ 제작
→ 승급
→ 지역 개방
```

강화·제련·레이드·특별 모집은 뒤에 개방한다.

## 실패 방지

- 첫 용병은 성장 가능한 직업 조합 보장
- 하급 포션 재료 지급
- 첫 강화는 확정
- 첫 승급 재료 지급
- 첫 부상은 즉시 치료 가능
