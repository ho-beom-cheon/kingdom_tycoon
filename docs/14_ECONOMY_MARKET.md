# 경제·시장

## 재화

### 용병 개인 골드

획득:

- 몬스터 현상금
- 재료·장비 판매
- 임무·레이드 보상

소비:

- 장비
- 포션
- 치료
- 승급비
- 선택적 수리(1.0 기본 비활성)

### 왕국 골드

획득:

- 용병의 상품 구매
- 시장 거래 수수료
- 왕국 목표·업적

소비:

- 시설 건설·업그레이드
- NPC 고용
- 생산 보조
- 숙소 확장
- 승급 지원

## 순환

```text
사냥
→ 용병 개인 골드·재료
→ 재료·장비 상점 판매
→ 개인 골드 증가, 왕국 재고 증가
→ 장비·포션 제작
→ 용병 구매
→ 왕국 골드 증가
→ 시설 투자
```

상점이 용병에게 지급하는 매입 골드는 게임 경제의 외부 유동성으로 처리하며 왕국 Treasury에서 직접 차감하지 않는다. 왕국 골드 부족으로 기본 루프가 영구 정지하지 않게 한다.

## 가격 정책

1.0은 자유 입력 대신 3단계 정책을 사용한다.

- 저가: 90%
- 표준: 100%
- 고가: 115%

용병의 성격과 구매 점수에 영향을 준다. 극단적 가격 악용을 막는다.

## 경제 안전장치

- 필수 하급 포션은 비상 생산 가능
- 튜토리얼 파산 방지 보조금
- 왕국 골드 0에서도 일반 사냥 가능
- 고급 생산이 핵심 재료를 모두 소비하지 않도록 예약 재고
