# 직업·스킬·전투 AI

## 직업 5종

| 직업 | 역할 | 핵심 행동 |
|---|---|---|
| 전사 | 근접 균형 딜러 | 가까운 적 압박, 낮은 체력 적 마무리 |
| 수호자 | 탱커 | 도발, 아군 보호, 전열 유지 |
| 궁수 | 원거리 단일 딜러 | 위험 적·약점 우선 |
| 마법사 | 범위·속성 딜러 | 밀집 적과 속성 약점 공략 |
| 성직자 | 회복·보조 | 낮은 체력 아군 회복, 보호막·축복 |

## 전투 방식

- 일반 사냥: 완전 자동.
- 레이드: 전투 전 편성, 포션, 부위 목표, 역할 정책을 결정하고 전투는 자동.
- 직접 스킬 버튼은 1.0에 넣지 않는다.

## 기본 전투 규칙

- 고정 Tick 또는 일정 주기 의사결정.
- 타겟 재평가는 너무 자주 하지 않는다.
- 스킬은 우선순위 + 조건으로 선택한다.
- 힐러는 Overheal을 최소화한다.
- 도발과 위협도는 명시적 수치로 관리한다.
- 군중 제어에는 보스 저항과 점감이 있다.

## AI 점수 예

```text
TargetScore = Threat
            + DistanceFit
            + LowHpBonus
            + WeaknessBonus
            + RolePriority
            - PathCost
```

## 파티 실패 방지

- 수호자 부재: 경고, 강제 금지 아님.
- 성직자 부재: 포션 요구량 경고.
- 최소 참가 랭크 미충족: 출전 차단.
- 예상 전투력 부족: 권장 경고.

## 기여도

직업별 승급 불공정을 막기 위해 다음을 합산한다.

- 피해량
- 유효 피해 흡수
- 유효 회복
- 버프·디버프 기여
- 생존 귀환
- 정예·보스 참여

각 항목은 전투 단위 상한을 둬 반복 악용을 방지한다.
