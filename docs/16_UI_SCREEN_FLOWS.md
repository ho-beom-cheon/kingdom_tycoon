# 화면별 흐름

## 왕국 메인

상단:

- 왕국 골드
- 프리미엄 재화
- 왕국 단계
- 중요 알림

중앙:

- 시설
- 용병·NPC 이동
- 상태 아이콘
- 건설 부지

우측 Drawer:

- 선택 용병·시설 요약
- 문제 원인
- 주요 행동

## 용병 목록·상세

필터:

- 직업
- 기본 등급
- 성장 랭크
- 상태
- 승급 가능
- 부상

상세 탭:

- 개요
- 장비
- 성장
- 기록

항상 현재 행동 이유를 노출한다.

## 시설

탭:

- 운영
- 생산
- 직원
- 업그레이드

생산 중단 원인을 `재료 부족`, `NPC 없음`, `시설 조건`, `재고 목표 달성`으로 구분한다.

## 제작

- 장비
- 포션
- 강화
- 제련
- 분해

강화는 성공 확률, 실패 결과, 보정 진행을 표시한다.

## 지역

- 잠금·개방 조건
- 최소 랭크
- 추천 전투력
- 주요 드롭
- 활동 용병
- 출입 정책

## 모집

주점:

- 후보 카드
- 고용비
- 갱신
- 잠금
- 숙소 슬롯

특별 모집:

- 확률
- 천장
- 사용 재화
- 기록
- 스킵 가능한 연출

## 레이드

준비:

- 파티
- 역할 경고
- 포션
- 부위 목표

전투:

- 보스 HP
- 부위 내구도
- 제한 시간
- 용병 상태

결과:

- 최초 토벌
- 지역 개방
- 재료
- 기여도
- 부상
