# TYCOON 상시 사냥 게임 체감 완성 최종 설계서 v1.0

> 상태: **FINAL / IMPLEMENTATION READY**
> 기준 이슈: #56
> 선행 계약: 통합 월드·상시 사냥·경제 순환 v1.0
> 범위: 전투·보상·귀환·성장 피드백, 지역 차이, 임시 VFX·효과음, 접근성
> 설계 미해결: **UNRESOLVED=0**

## 1. 목표

완성된 상시 사냥 루프의 상태가 텍스트만 바뀌는 시뮬레이션처럼 보이지 않도록 한다. 사용자는 월드를 보는 것만으로 누가 무엇을 공격했고, 스킬이 발동했는지, 몬스터가 죽었는지, 무엇을 획득했는지, 왜 귀환했고 어떤 성장을 마쳤는지를 구분할 수 있어야 한다.

이번 단계는 전투 공식이나 경제 권위를 바꾸지 않는다. 기존 조회 DTO의 실제 변화만 감지해 표현 이벤트로 변환하며, 표현이 실패하거나 꺼져도 Save·전투·보상 결과는 동일해야 한다.

## 2. 포함·제외 범위

### 2.1 포함

- 기본 공격의 짧은 돌진, 몬스터 타격 섬광, 피해 숫자
- 스킬 공격의 별도 색상·크기·펄스와 효과음
- 몬스터 처치, 재생성 대기, 재등장 피드백
- 전리품·현상금·가방 증가, 귀환·정산, 스킬 훈련·장비 강화 피드
- 용병 카드의 현재 체력·가방·스킬 총 레벨·최고 강화 수치
- 지역별 위험도와 대표 전리품을 canonical 콘텐츠에서 파생해 표시
- 외부 파일 없는 절차형 짧은 효과음과 재사용 가능한 임시 VFX
- 효과음 켜기/끄기, 모션 보통/감소 설정
- 한국어·16:9~20:9·Safe Area·64px 터치 계약 유지

### 2.2 제외

- 전투 피해·드롭 확률·귀환 조건·상점 AI 변경
- Save 또는 콘텐츠 스키마 버전 증가
- 카메라 흔들림, 진동, 빠른 전면 점멸
- 외부 무료·유료 Sprite, Audio, VFX 에셋 도입
- 캐릭터 스프라이트 애니메이터 최종본
- 수동 Unity 실행 증빙

## 3. 표현 이벤트 계약

`WorldHuntFeedbackTracker`는 직전 `ContinuousHuntOverviewDto`와 새 DTO를 비교해 다음 이벤트를 만든다.

| 이벤트 | 권위 변화 | 표시 |
|---|---|---|
| `BASIC_HIT` | 몬스터 HP 감소 + 공격자 최근 피해 | 흰 피해 숫자, 짧은 섬광 |
| `SKILL_HIT` | 몬스터 HP 감소 + `lastSkillId` 존재 | 금색 피해 숫자, 확장 펄스 |
| `MONSTER_DEFEATED` | `ACTIVE → RESPAWNING` | 처치 문구, 축소·소멸 |
| `MONSTER_RESPAWNED` | 같은 슬롯의 새 활성 인스턴스 | 재등장 펄스 |
| `LOOT_COLLECTED` | 용병 가방 사용량 증가 | 청록 보상 피드 |
| `BOUNTY_EARNED` | 미정산 현상금 증가 | 금색 보상 피드 |
| `RETURNING` | 상태가 `RETURN_TOWN`으로 전환 | 귀환 화살표·상태 피드 |
| `SETTLED` | 누적 수익 증가 또는 가방 비움 | 정산 피드 |
| `SKILL_TRAINED` | 스킬 총 레벨 증가 | 성장 피드·고음 큐 |
| `EQUIPMENT_ENHANCED` | 최고 강화 수치 증가 | 강화 피드·고음 큐 |

첫 관찰은 기준선만 저장하고 이벤트를 만들지 않는다. 리비전이 같으면 중복 이벤트를 만들지 않는다. 몬스터와 용병은 인스턴스 ID로 연결하며, 대상이 사라져도 직전 프레임의 목표 관계로 처치 이벤트를 귀속한다.

표현 이벤트는 Save에 저장하지 않는다. 서비스 커밋이 끝난 조회 결과에서만 파생되므로 표현 실패가 게임 상태를 선행하지 않는다.

## 4. 전투 피드백

- 공격자는 목표 방향으로 최대 24px 돌진한 뒤 원위치로 돌아온다.
- 일반 타격 섬광은 0.16초, 스킬 펄스는 0.36초를 기본값으로 한다.
- 피해 숫자는 0.85초 동안 36px 상승하고 투명해진다.
- 기본 피해는 흰색, 스킬 피해는 금색, 처치는 주홍색으로 구분한다.
- 엘리트는 보라색 외곽과 `정예` 형태 표식을 함께 사용한다.
- 몬스터 사망은 0.7배 축소 후 숨기며 `재생성 중` 표시는 유지한다.
- 재생성은 0.8배에서 1.08배까지 한 번 확장 후 정상 크기로 돌아온다.

모션 감소 모드에서는 돌진·바운스·지속 펄스를 끄고 피해 숫자, 색상 변화, 상태 문구만 유지한다. 효과음이 꺼져도 모든 상태를 시각적으로 식별할 수 있어야 한다.

## 5. 보상·귀환·성장 피드

월드 뷰포트 우측 상단에 최근 피드 3개를 표시한다. 각 행은 4초 후 사라지며 새 이벤트가 위에 들어온다. 동일 리비전의 같은 유형·대상을 중복 추가하지 않는다.

- 전리품: `용병명 · 전리품 +N`
- 현상금: `용병명 · 현상금 +N골드`
- 귀환: `용병명 · 체력/가방 점검 후 귀환`
- 정산: `용병명 · 정산 +N골드`
- 스킬: `용병명 · 스킬 총 레벨 N`
- 강화: `용병명 · 장비 최고 +N`

용병 카드에는 `체력`, `가방`, `스킬`, `강화`를 항상 표시해 한 번의 성장 피드가 사라진 뒤에도 결과를 확인할 수 있게 한다.

## 6. 지역 차이 표시

지역의 위험도는 `regions.csv`의 티어에서 파생한다.

| 티어 | 한국어 위험도 |
|---|---|
| 1 | 안정 |
| 2 | 주의 |
| 3 | 위험 |
| 4 | 고위험 |
| 5 | 극한 |

대표 전리품은 해당 지역 encounter에 포함된 몬스터들의 `loot_entries.csv`를 모아 중복 제거한 뒤, 한국어 아이템명과 `장비`를 최대 2개 표시한다. ID나 영문 폴백은 사용자 화면에 노출하지 않는다.

지역 카드의 테마색은 기존 정책을 유지하고 위험도는 형태가 다른 배지와 텍스트로 함께 표시한다. 색상만으로 난이도를 전달하지 않는다.

## 7. 효과음 계약

외부 음원 없이 `AudioClip.Create`로 짧은 단음 큐를 한 번 생성해 재사용한다.

- 일반 타격: 낮고 짧은 사각파 계열
- 스킬: 중고음 상승 큐
- 보상·정산: 밝은 단음
- 스킬 성장·강화: 두 단계 상승 큐

전체 음량 기본값은 22%이며 일상 타격은 보상보다 작게 재생한다. 동시 이벤트가 많아도 프레임당 같은 유형은 한 번만 재생한다. AudioClip은 이벤트마다 새로 만들지 않는다.

효과음 설정은 로컬 `PlayerPrefs`에만 저장한다. 게임 Save와 서버 동기화 대상이 아니다.

## 8. 성능·풀링

- 25개 몬스터 뷰마다 피해 텍스트와 펄스 이미지를 한 번 생성해 재사용한다.
- 최근 피드 행은 3개 고정 배열로 재사용한다.
- 절차형 AudioClip은 화면당 4종만 캐시한다.
- Update에서 LINQ·GameObject 생성·AudioClip 생성을 반복하지 않는다.
- 화면을 닫으면 효과음과 진행 중 피드백을 중지하지만 전투 서비스는 계속 진행한다.

## 9. 접근성·UI 안정성

- 상단에 `효과음 켬/끔`, `모션 보통/감소` 버튼을 둔다.
- 버튼은 각각 120×64 이상이며 `왕국으로` 버튼과 겹치지 않는다.
- 최근 피드는 월드 조작을 가로채지 않도록 raycast를 받지 않는다.
- 피해 숫자와 피드는 Safe Area 밖으로 나가지 않는다.
- 1920×1080과 2400×1080에서 헤더, 월드, 보상 피드, 하단 서랍이 겹치지 않는다.
- 사용자 노출 문구는 한국어만 사용한다.

## 10. 정책 데이터

다음 값은 `world-hunt.rules.json.feedback`에 둔다.

- 타격 섬광·스킬 펄스·피해 숫자·보상 피드 지속 시간
- 최대 피드 행 수
- 기본 음량
- 일반 타격·스킬·보상·성장 주파수

파서는 범위를 검증하고 누락·비정상 값이면 Bootstrap을 실패시킨다. View에 같은 값을 중복 상수로 두지 않는다.

## 11. 테스트 수용 기준

### EditMode

- 첫 관찰과 같은 리비전은 이벤트 0건이다.
- 실제 HP 감소가 기본/스킬 타격 이벤트로 구분된다.
- 사망·재생성·가방·현상금·정산·스킬·강화 변화가 올바른 대상 이벤트로 변환된다.
- 지역 위험도와 대표 전리품이 canonical 콘텐츠에서 한국어로 만들어진다.
- 피드백 정책의 유효·무효 범위를 검증한다.

### PlayMode

- 타격 후 피해 숫자와 섬광이 활성화된다.
- 스킬과 일반 공격의 색상·텍스트가 구분된다.
- 최근 보상 피드는 최대 3행이며 시간이 지나면 재사용된다.
- 용병 카드에 스킬·강화가 표시된다.
- 효과음·모션 버튼이 상태를 바꾸고 로컬 설정을 유지한다.
- 모션 감소에서도 전투·보상 상태를 텍스트와 색상으로 확인할 수 있다.
- 16:9·20:9에서 모든 활성 버튼이 64px 이상이고 형제 버튼이 겹치지 않는다.

## 12. 완료 정의

최종 설계·완결성 검토·정책·표현 추적기·Presenter·EditMode·PlayMode·CI·구현 증거가 같은 이슈 브랜치에 있고 전체 CI가 통과해야 한다. `saveVersion`, `contentVersion`, 전투·경제 결과가 선행 계약과 같아야 하며 수동 실행은 완료 정의에서 제외한다.
