# 코어 런타임 성능 안정화 최종 설계 v1.0

## 1. 목적

통합 생활 월드의 시각 품질과 자동 사냥 규칙을 유지하면서 입력 정지, 프레임 급락, 주기적 멈춤을 제거한다. 이 문서는 이슈 #62의 런타임 성능 계약이며 기존 Save 원자성·복구·마이그레이션 계약을 변경하지 않는다.

## 2. 확인된 병목

- 자동 사냥 갱신이 전체 Save 문서를 복제한 뒤 매번 원자적 디스크 저장을 실행한다.
- 원자적 저장은 스키마 검증, 임시 파일 검증, 3세대 백업 회전, 활성 파일 재검증을 메인 스레드에서 수행한다.
- 오프라인 누적 진행을 최대 240단계씩 용병별로 한 프레임에서 처리할 수 있다.
- 상태 발행마다 모든 지역·몬스터·용병·텍스트를 다시 설정한다.
- 월드, HUD, 팝업과 움직이는 객체가 하나의 uGUI Canvas에 포함되어 작은 변경도 넓은 Canvas 재빌드를 유발한다.

## 3. 성능 목표

- 중급 Android 기기에서 30 FPS 하한을 유지하고 고성능 모드에서 60 FPS를 목표로 한다.
- 일반 입력 프레임의 메인 스레드 작업은 16.6ms 예산을 넘지 않도록 분산한다.
- 카메라 드래그와 UI 클릭은 저장·누적 진행 계산보다 우선한다.
- 자동 사냥 누적 계산은 한 프레임에 최대 24개 상태 전이만 처리한다.
- 자동 사냥 화면 발행은 최대 5 Hz로 병합하고 장식 애니메이션은 최대 30 Hz로 제한한다.
- 일반 자동 사냥 디스크 저장은 20초 단위로 병합하며 마지막 입력 후 1.5초 이상 유휴 상태에서만 실행한다.

## 4. 시뮬레이션 계약

1. `AdvanceTo`는 테스트·오프라인 정산용 완전 진행 API로 유지한다.
2. 실시간 화면은 `AdvanceBudgetedTo`를 사용한다.
3. 예산이 소진된 경우 남은 상태는 다음 프레임에 이어서 처리한다.
4. 계산 결과는 먼저 메모리 문서에 반영한다.
5. 화면 DTO 발행은 계산과 분리하여 여러 계산 결과를 한 번에 발행한다.
6. 배치 순서, 대상 예약, 전리품, 성장 및 경제 규칙은 기존 결정론을 유지한다.

## 5. 저장 계약

- 시설 건설, 모집, 구매 등 기존 명시적 거래는 기존 원자적 즉시 저장을 유지한다.
- 자동 사냥의 반복 상태 전이는 메모리에 병합하고 `HasPendingPersistence`로 추적한다.
- 유휴 저장, 앱 일시정지, 앱 종료, 서비스 종료 시 최신 메모리 스냅샷을 기존 `ISaveRepository.Save`로 저장한다.
- 다른 게임 서비스가 먼저 저장하면 해당 스냅샷에 현재 자동 사냥 상태가 포함되므로 데이터가 유실되지 않는다.
- 강제 종료 시 유실 가능한 일반 자동 사냥 진행의 상한은 마지막 병합 저장 이후 20초이며 이 값은 `TUNABLE`이다.
- 임시 파일, 활성 파일 교체, 3세대 백업, 체크섬, 스키마 검증 및 복구 우선순위는 그대로 유지한다.

## 6. 렌더링 계약

- 루트 HUD Canvas와 월드 Canvas를 분리한다.
- 월드 정적 레이어, 지역 레이어, 용병 레이어를 중첩 Canvas로 격리한다.
- 움직이는 용병이나 몬스터의 `RectTransform` 변경이 HUD와 정적 월드 전체를 재빌드하지 않게 한다.
- 지역이 화면 밖에 있을 때 해당 지역 몬스터의 장식 이동을 생략한다.
- 텍스트, 색상, 스프라이트, 활성 상태는 값이 실제로 변경될 때만 적용한다.
- 메뉴·배치 패널·시설 패널·캐릭터 상세가 열린 동안 배경 장식 갱신 빈도를 낮추되 전투 상태 계산은 유지한다.
- 현재 픽셀 아트, 지도 배치, 카메라 구도, 건물과 캐릭터 상호작용은 유지한다.

## 7. 입력 우선 계약

- 드래그 중에는 자동 사냥 계산·화면 발행·디스크 저장을 수행하지 않는다.
- 버튼 입력 직후 1.5초 동안 자동 저장을 연기한다.
- 입력과 같은 프레임에 전체 화면 갱신을 중복 실행하지 않는다.
- 드래그 델타는 렌더 프레임당 한 번만 적용한다.

## 8. 계측과 회귀 방지

- 자동 사냥 계산, 화면 갱신, 월드 애니메이션, 병합 저장에 `ProfilerMarker`를 둔다.
- EditMode에서 반복 계산이 디스크 revision을 증가시키지 않고 한 번의 flush로 합쳐지는지 검증한다.
- EditMode에서 프레임 예산보다 많은 상태 전이를 한 호출에서 처리하지 않는지 검증한다.
- PlayMode에서 월드가 격리 Canvas를 사용하고 카메라 입력이 한 프레임에 병합되는지 검증한다.
- 전체 PlayMode, 저장 계약, 콘텐츠 계약 및 저장소 CI를 통과해야 한다.

## 9. 완료 기준

- 메뉴와 캐릭터를 연속 클릭해도 자동 사냥 저장 때문에 입력이 멈추지 않는다.
- 장시간 누적 진행이 한 프레임에 몰리지 않는다.
- 자동 사냥 결과가 앱 일시정지·종료 후 다시 로드된다.
- 같은 화면 구성과 자산 품질을 유지한다.
- Unity Profiler에서 반복 디스크 저장과 루트 Canvas 전체 재빌드가 일반 플레이 구간에서 제거된다.
