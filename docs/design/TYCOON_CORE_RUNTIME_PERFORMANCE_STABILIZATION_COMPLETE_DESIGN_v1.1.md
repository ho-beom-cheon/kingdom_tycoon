# 코어 런타임 성능 안정화 최종 설계 v1.1

## 1. 목적

v1.0의 저장 병합·프레임 분산·Canvas 격리 계약을 유지하면서 실제 장기 플레이 Save에서 확인된 대형 문서 복제와 입력 경합을 제거한다. 화면 구성, 픽셀 자산, 자동 사냥 결과, Save schema와 복구 우선순위는 변경하지 않는다.

## 2. 실측 기준선

- 로컬 장기 플레이 Save는 약 1MB까지 성장했다.
- `operationJournal`은 667행, 약 746KB로 전체 Save의 대부분을 차지했다.
- 자동 사냥 읽기 모델 생성 전 `Snapshot()`을 호출하면 화면에 필요한 약 30KB 이하의 월드 상태를 읽기 위해 전체 저널과 경제 원장을 복제한다.
- 자동 사냥 임시 상태 적용 과정에서도 이미 독립 복제된 draft를 다시 `DeepClone()`해 같은 대형 문서를 중복 복제한다.
- 클릭·드래그 프레임과 자동 사냥 계산 프레임이 겹칠 수 있으며, 배치가 없는 지역의 장식 모션도 활성 지역과 같은 빈도로 uGUI 정점을 갱신한다.

## 3. Save 읽기·임시 상태 계약

1. `GetOverview`, 변경 이벤트 발행, 다음 실행 시각 계산은 현재 문서를 읽기 전용으로 참조한다.
2. 읽기 경로는 현재 문서의 `JToken`을 변경하거나 외부에 노출하지 않는다.
3. 자동 사냥 mutation은 기존과 같이 독립 `Snapshot()` draft에서 수행한다.
4. 검증을 마친 draft는 호출자가 더 이상 변경하지 않는 소유권 이전 계약으로 `FacilityGameService`에 반영한다.
5. 반영 후 draft를 다시 `DeepClone()`하지 않는다.
6. 디스크 저장, 명시적 거래, 백업 생성, 스키마 검증과 복구 시에는 기존 방어적 복제를 유지한다.
7. `operationJournal`의 보존·멱등성·재생 계약은 변경하지 않는다. 저널 pruning은 별도 Save 계약 없이는 수행하지 않는다.

## 4. 입력 우선 계약

- 마우스 버튼 또는 터치가 눌린 동안 자동 사냥 계산과 장식 애니메이션을 실행하지 않는다.
- 버튼 콜백과 드래그 종료 후 최소 150ms 동안 무거운 계산을 양보한다.
- 입력 양보는 시뮬레이션을 삭제하지 않고 다음 실행 프레임으로 미룬다.
- 카메라 직접 조작과 관성 이동은 기존 위치·줌·경계 계약을 유지한다.

## 5. 렌더링 계약

- 배치 용병이 있는 지역은 최대 24Hz로 전투·장식 모션을 갱신한다.
- 배치가 없고 선택되지 않은 지역은 최대 8Hz로 주변 장식 모션을 갱신한다.
- 패널이 열린 동안 전체 월드 애니메이션 상한은 12Hz다.
- 타격 flash·pulse가 끝난 상태의 색상은 값이 달라질 때만 쓴다.
- 보상 피드 alpha도 값이 달라질 때만 쓴다.
- 캐릭터, 몬스터, 건물, 지도와 무료 에셋은 제거하거나 저해상도로 교체하지 않는다.

## 6. 성능 목표

- 장기 Save에서도 일반 자동 사냥 상태 갱신당 전체 Save 복제는 1회 이하다.
- 읽기 모델 생성은 전체 Save 복제를 수행하지 않는다.
- 클릭·드래그가 감지된 프레임에는 자동 사냥 계산이 실행되지 않는다.
- 배치 없는 사냥터의 uGUI 동적 쓰기는 활성 사냥터 대비 3분의 1 이하로 제한한다.
- 모바일 세로형 화면의 정보량과 픽셀 자산 품질을 유지한다.

## 7. 검증

- EditMode에서 읽기 모델 생성이 현재 Save를 변경하지 않음을 검증한다.
- EditMode에서 임시 draft 반영 후 revision·프로필 검증과 상태 결과가 유지됨을 검증한다.
- PlayMode에서 Canvas 격리, 복수 배치, 건물·캐릭터 클릭, 모바일 세로 레이아웃 회귀를 검증한다.
- 전체 EditMode·PlayMode, Save 계약, 콘텐츠 계약을 실행한다.
- Profiler marker `KingdomTycoon.World.Simulation`, `Refresh`, `Animation`, `Persistence`를 유지한다.

## 8. 완료 기준

- 장기 Save를 사용하는 Editor Play Mode에서 클릭과 카메라 입력이 자동 사냥 갱신보다 우선한다.
- 전투·보상·성장 결과와 종료 저장 결과가 기존과 동일하다.
- 화면 자산이나 기능을 제거하지 않고 대형 문서 중복 복제와 불필요한 Graphic 쓰기를 제거한다.
