- 상태: `FINAL / IMPLEMENTATION READY`
- 기준일: 2026-07-21 KST
- 관련 이슈: `#60 기능: 세로형 통합 왕국·사냥 월드 구현`
- 선행 계약: `TYCOON_CORE_WORLD_HUNT_ECONOMY_COMPLETE_DESIGN_v1.0.md`, `TYCOON_CORE_HUNT_GAME_FEEL_COMPLETE_DESIGN_v1.0.md`, `TYCOON_CORE_HUNT_VISUAL_POLISH_COMPLETE_DESIGN_v1.0.md`
- 설계 미해결: `UNRESOLVED=0`

## 1. 제품 목표

플레이어가 버튼으로 왕국과 사냥터 화면을 오가는 구조를 끝내고, 중앙 왕국과 사방 사냥터가 한 장의 살아 있는 모바일 월드로 보이게 한다. 용병은 지정된 사냥터에서 계속 사냥하고 왕국에 돌아와 판매·치료·구매·훈련·강화를 수행한 뒤 다시 사냥터로 향한다. 플레이어는 이 순환을 드래그와 확대·축소로 관찰하고, 사냥터를 눌러 여러 용병의 배치를 관리한다.

이 기능은 외부 상용 게임의 그래픽·UI·명칭·배치를 복제하지 않는다. 참고 작품에서 학습하는 것은 다음 세 가지뿐이다.

- 첫 화면에서 자율 생활과 전투가 동시에 보이는 관찰성
- 하나의 월드에서 왕국과 사냥 구역을 탐색하는 카메라 문법
- 시설 이용과 전투 상태가 캐릭터 이동으로 읽히는 생활감

## 2. 최종 범위

### 2.1 포함

- 1080×1920 세로형 모바일 기준 화면과 1080×2400 장화면 대응
- 중앙 왕국과 북·동·남·서 사냥 구역의 2차원 연속 월드
- 시작·복귀 시 중앙 왕국 정렬
- 한 손가락 2축 드래그, 핀치 확대·축소, 가벼운 관성, 경계 클램프
- 드래그와 탭 구분 및 사냥터 오조작 방지
- 고정 시설과 시설 입구·왕국 출입구·사냥터 접근점
- 용병 상태를 왕국 시설·길·사냥터 좌표로 변환하는 표현 라우팅
- 몬스터의 제한 배회·교전·피격·사망·전리품·재등장 표현
- 사냥터 바텀 시트와 여러 용병 동시 배치·해제
- 화면 우측 상단 통합 메뉴와 기존 하단 고정 내비게이션 숨김
- 사용자 노출 문자열 한국어 단일화
- 상업 이용 가능한 CC0 무료 픽셀 에셋의 선별 적용
- 기존 내부 픽셀 자산의 결정적 폴백 유지
- EditMode·PlayMode·CI·구현 증적

### 2.2 제외

- 자유 건물 배치·이동·회전
- 수동 조이스틱·공격·스킬 버튼
- 월드 미니맵, 자동 카메라 연출, 필드 보스 카메라
- 펫, 길드, PvP, 환생, 다중 직업, 여행 콘텐츠
- 포만감·기분·기력 등 별도 생활 수치 추가
- 뽑기·광고·결제 UX 추가
- 유료 에셋 구매
- Save 또는 콘텐츠 버전 증가
- 사용자가 직접 Unity 창을 조작하는 수동 실행 단계

## 3. 기존 계약 충돌과 해석

| 기존 계약 | 이번 최종 결정 | 영향 |
|---|---|---|
| 가로 1920×1080이 주 기준 | 통합 생활 월드만 세로 1080×1920을 주 기준으로 대체 | 다른 관리 화면은 기존 가로 계약 유지, 통합 월드는 가로에서도 안전 축소 지원 |
| 지역이 월드 X축으로 일렬 배치 | 기존 `worldX`는 콘텐츠 순서 호환값으로만 유지하고 View가 2차원 좌표에 매핑 | Save·서비스·CSV 변경 없음 |
| 카메라는 X축 드래그만 허용 | X/Y 드래그와 핀치 줌으로 대체 | 표현 계층과 PlayMode 테스트 변경 |
| 사냥터 선택 시 하단 고정 Drawer | 월드 관찰을 덮지 않는 상황형 바텀 시트로 대체 | 선택하지 않았을 때 하단 UI 없음 |
| 왕국/용병/제작/사냥터/모집 하단 내비게이션 | 우측 상단 메뉴에 통합 | 기존 화면 진입 서비스는 재사용 |
| 왕국은 한 장의 랜드마크 카드 | 시설과 길이 보이는 중앙 생활 구역으로 확장 | 시설 도메인 상태는 변경하지 않음 |

이번 문서가 통합 생활 월드 화면에 한해 위 항목의 최신 계약이다. 선행 문서의 전투·전리품·경제·자동 성장·Save 계약은 그대로 유효하다.

## 4. 화면과 Safe Area 계약

### 4.1 기준 해상도

- 주 기준: 1080×1920, 세로 9:16
- 장화면: 1080×2400, 세로 9:20
- 호환 기준: 1920×1080, 2400×1080
- `CanvasScaler`: `ScaleWithScreenSize`, 참조 1080×1920
- 모든 고정 HUD는 `SafeAreaFitter` 아래에 둔다.
- 주요 터치 영역은 참조 해상도에서 64×64px 이상이다.
- 관리 패널이 열려도 닫기·뒤로·왕국 복귀 동작을 잃지 않는다.

### 4.2 첫 화면 계층

```text
Safe Area
├─ World Viewport (전체 배경)
│  └─ Draggable World
│     ├─ 지면·길·장식
│     ├─ 사냥 구역
│     ├─ 중앙 왕국·시설
│     ├─ 몬스터
│     ├─ 용병
│     └─ 전투·보상 피드백
├─ 좌상단 상태 HUD
├─ 우상단 왕국 복귀·알림·메뉴
├─ 우측 최근 소식(최대 3행)
├─ 통합 메뉴(요청 시만)
└─ 사냥터 배치 바텀 시트(선택 시만)
```

첫 화면에서 고정 하단 내비게이션은 존재하지 않는다. 월드가 제품의 첫 시각적 초점이며, HUD는 월드 가장자리에 떠 있는 컴팩트 오버레이다.

## 5. 2차원 월드 계약

### 5.1 논리 크기와 구역

- 월드 논리 크기: 3000×4200 UI 단위
- 중앙 왕국: `(0, 0)`, 약 1200×1050
- 지역 루트 좌표는 View 전용 상수이며 Save에 기록하지 않는다.

| 지역 | 구역 | 월드 좌표 | 테마 |
|---|---|---:|---|
| `REGION_R01` | 북쪽 내곽 | `(0, 1250)` | 초원 |
| `REGION_R02` | 동쪽 | `(900, 350)` | 숲 |
| `REGION_R03` | 남쪽 | `(0, -1300)` | 광산 |
| `REGION_R04` | 서쪽 | `(-900, 350)` | 늪지 |
| `REGION_R05` | 북쪽 외곽 | `(780, 1500)` | 설원 유적 |

사방은 방향당 하나의 장면을 뜻하지 않는다. 북쪽처럼 같은 방향에 티어가 다른 사냥터가 둘 이상 놓일 수 있다. 모든 구역은 같은 `WorldContent`에 있고 장면 전환 없이 이어진다.

### 5.2 렌더 순서

1. 원거리 배경색
2. 지면 타일
3. 길·물·경계
4. 낮은 장식
5. 시설·높은 장식
6. 몬스터·용병(Y 기준 정렬 효과)
7. 이름·체력·상태
8. 피해 숫자·드롭·최근 소식
9. 화면 고정 HUD·시트

uGUI 기반 MVP에서는 계층 순서와 `SetAsLastSibling`으로 Y 정렬 효과를 낸다. 이후 Tilemap/SpriteRenderer 교체 시 논리 좌표와 상태 라우팅 계약을 유지한다.

### 5.3 길과 진입점

- 왕국 중심에서 북·동·남·서 출입구로 길이 이어진다.
- 각 사냥터에는 왕국 방향 접근점, 순찰점 3개, 몬스터 생성점 5개가 있다.
- 시설에는 입구점 하나와 대기점 둘을 둔다.
- 길·입구·순찰점은 표현 계층의 정적 노드이며 Save에 저장하지 않는다.

## 6. 카메라와 입력 계약

### 6.1 이동

- 한 손가락 드래그는 X/Y 축을 동시에 이동한다.
- 포인터 델타는 Canvas 스케일로 보정한다.
- 드래그 종료 속도를 감쇠해 짧은 관성을 적용한다.
- 콘텐츠가 뷰포트보다 작은 축은 중앙에 고정한다.
- 확대 배율을 반영해 양축 경계를 클램프한다.

### 6.2 확대·축소

- 핀치와 테스트용 휠 입력을 지원한다.
- 최소 0.65배, 최대 1.35배다.
- 확대 중심은 두 손가락 중점 또는 포인터 위치다.
- 배율 변경 직후 경계를 다시 클램프한다.
- 접근성 모션 감소 설정은 관성을 끄지만 확대·축소는 유지한다.

### 6.3 탭과 드래그 분리

- 누적 이동 18 UI 단위 이하는 탭 후보이다.
- 기준을 넘으면 해당 포인터의 다음 클릭 한 번을 소비한다.
- 드래그 후 사냥터 배치 시트가 열리거나 명령이 실행되면 테스트 실패다.
- 사냥터 터치 자체는 Save를 변경하지 않고 시트만 연다.

### 6.4 왕국 복귀

- 우측 상단 집 버튼은 배율 1.0과 중앙 왕국 `(0,0)`으로 복귀한다.
- 화면을 처음 열 때도 같은 동작을 수행한다.
- 화면이 열린 동안 마지막 관찰 위치는 유지할 수 있으나 앱 재시작 Save 대상은 아니다.

## 7. 왕국 생활 구역

### 7.1 고정 시설

| 시설 | 좌표 | 표시 역할 |
|---|---:|---|
| 주점 | `(-330, 260)` | 대기·모집·휴식 |
| 상점 | `(330, 240)` | 판매·물약·장비 구매 |
| 대장간 | `(-330, -230)` | 제작·장비 강화 |
| 치료소 | `(330, -230)` | 회복·부상 치료 |
| 모험가 길드 | `(0, 30)` | 훈련·승급·왕국 중심 |

시설은 유효한 콘텐츠 ID와 한국어 이름을 표시한다. 자유 배치는 하지 않으며, 시설 클릭은 기존 상세 화면을 열 수 있는 확장 지점만 남긴다.

### 7.2 용병 상태 라우팅

| 서비스 상태 | 표현 목적지 | 표현 |
|---|---|---|
| `IDLE_TOWN` | 주점/광장 | 짧은 배회와 대기 |
| `TRAVEL_TO_REGION` | 배치 사냥터 접근점 | 왕국 출입구에서 사냥터로 이동 |
| `FIND_TARGET` | 사냥터 순찰점 | 범위 내 순찰 |
| `COMBAT` | 목표 몬스터 공격점 | 사거리 접근·공격 돌진 |
| `LOOT` | 처치 몬스터/드롭점 | 짧은 수집 이동 |
| `CONTINUE_DECISION` | 사냥터 대기점 | 상태 점검 |
| `RETURN_TOWN` | 왕국 출입구 | 사냥터에서 왕국으로 이동 |
| `SELL_LOOT` | 상점 | 판매 아이콘·소식 |
| `HEAL` | 치료소 | 회복 표시 |
| `BUY_CONSUMABLES` | 상점 | 물약 구매 표시 |
| `EVALUATE_EQUIPMENT` | 상점 앞 | 장비 비교 표시 |
| `BUY_EQUIPMENT` | 상점 | 장비 구매 표시 |
| `TRAIN_SKILLS` | 모험가 길드 | 훈련 표시 |
| `ENHANCE_EQUIPMENT` | 대장간 | 강화 표시 |

Presenter는 조회 DTO를 좌표로 변환할 뿐 상태를 바꾸지 않는다. 상태 전환·피해·가방·골드·장비는 `ContinuousHuntGameService`만 변경한다.

### 7.3 이동 규칙

- 화면이 생성될 때 각 용병을 현재 상태의 표준 노드에 배치한다.
- 상태 또는 목표가 바뀌면 현재 표시 좌표에서 새 노드까지 선형 보간한다.
- 같은 노드로 향하는 용병은 ID 해시 기반 오프셋을 받아 겹치지 않는다.
- 2초 이상 목표와 거리가 줄지 않으면 표준 노드로 복구한다.
- 캐릭터 간 물리 충돌은 사용하지 않는다.
- 연속 픽셀 좌표는 Save하지 않는다.

## 8. 사냥터·몬스터·전투 표현

### 8.1 사냥터

- 테마색과 CC0 지면/장식 일부로 넓은 필드 패치를 만든다.
- 지역명, 티어, 권장 전투력, 현재 배치 수는 작은 월드 라벨로 표시한다.
- 잠긴 지역은 채도를 낮추고 잠금 이유를 한국어로 표시한다.
- 카드 목록처럼 동일 크기 상자를 나열하지 않는다.

### 8.2 몬스터

- `ACTIVE`: 생성점 주변 반경 안에서 결정적 위상으로 천천히 배회한다.
- 표적이 있으면 공격점 쪽으로 짧게 접근한다.
- 피격 시 섬광·피해 숫자, 처치 시 펄스·드롭, `RESPAWNING` 시 저채도와 남은 상태를 표시한다.
- 재등장 시 같은 슬롯의 생성점에서 다시 보인다.
- 화면 밖에서는 배회·장식 애니메이션을 단순화해 할당을 만들지 않는다.

### 8.3 전투 권위

- 몬스터 위치는 표현용이다. 공격 가능 여부와 피해는 서비스 상태와 사건이 권위다.
- View는 거리로 피해를 계산하거나 전투 명령을 만들지 않는다.
- 여러 용병이 같은 몬스터를 공격할 수 있고 스프라이트 오프셋으로 겹침을 줄인다.
- 레이드 보스는 일반 사냥터에 추가하지 않는다.

## 9. 사냥터 복수 배치 시트

사냥터를 탭하면 화면 하단 42% 이내 높이의 시트를 연다.

### 9.1 정보

- 지역명·티어·안정/주의/위험 배지
- 권장 전투력·배치 수/최대 배치 수
- 출현 몬스터와 주요 드롭 요약
- 잠금 이유 또는 배치 안내

### 9.2 용병 행

- 직업 아이콘, 이름, 레벨·체력, 현재 위치, 가방 사용량
- 선택 사냥터 배치 여부
- 다른 사냥터 배치 중이면 이동 대상 지역을 명확히 표시
- 저체력·권장 전투력 미달 경고
- 행 전체 64px 이상 터치 영역

### 9.3 명령

- 해금 지역의 용병 행을 누르면 `Assign(instanceId, regionId)` 또는 `Unassign(instanceId)`를 정확히 한 번 호출한다.
- 한 사냥터에 여러 용병을 순차 선택할 수 있다.
- 배치 상한, 잠금, 저장 충돌 오류는 한국어 상태선에 표시하고 기존 상태를 유지한다.
- 시트 닫기는 Save를 변경하지 않는다.

## 14. 자동 테스트 수용 기준

### 14.1 EditMode

- 다섯 지역이 네 방향 구역에 매핑되고 중앙 왕국과 겹치지 않는다.
- 모든 서비스 상태가 유효한 시설·출입구·사냥터 목적지로 매핑된다.
- 동일 용병 ID는 동일 겹침 방지 오프셋을 만든다.
- 외부 자산 등록 행이 CC0·0원·상업 이용/수정 허용으로 파싱된다.
- 내부 픽셀 폴백 21개 계약을 유지한다.

### 14.2 PlayMode

- Bootstrap 완료 뒤 첫 주 화면에 생활 월드가 열리고 중앙 왕국이 보인다.
- 월드에 시설 5개, 사냥터 5개, 몬스터 뷰 25개가 존재한다.
- 북·동·남·서에 사냥터가 있고 X/Y 드래그가 각각 동작한다.
- 0.65~1.35 범위에서 확대·축소하고 양축 경계를 넘지 않는다.
- 드래그 뒤 사냥터 시트가 열리지 않는다.
- 사냥터 탭으로 시트가 열리고 두 명 이상을 같은 지역에 배치할 수 있다.
- 상태 변경 시 용병 목적지가 사냥터·상점·치료소·길드·대장간으로 바뀐다.
- 우측 상단 메뉴가 존재하고 하단 기본 내비게이션은 숨겨진다.
- 1080×1920, 1080×2400에서 모든 활성 버튼이 64×64 이상이며 형제끼리 겹치지 않는다.
- 사용자 노출 문자열에 대체 문자와 금지된 영문 UI 문구가 없다.
- CC0 텍스처가 지면/장식에 실제 적용되고 내부 캐릭터 폴백도 유효하다.

### 14.3 회귀
