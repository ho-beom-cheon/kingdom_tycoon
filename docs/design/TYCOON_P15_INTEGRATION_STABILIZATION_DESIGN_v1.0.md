# P15 통합 안정화 최종 설계서 v1.0

## 1. 목적

P16 시각 디자인 고도화 전에 P04~P15 기능을 하나의 플레이 흐름으로 묶고, 화면 겹침·접근 불가·가짜 진행·한영 혼용을 제거한다. 이 단계는 신규 콘텐츠 단계가 아니라 P15 완료 조건을 충족하기 위한 통합 결함 수정 단계다.

## 2. 기준선 결함

1. 각 단계가 독립적으로 하단 버튼을 추가해 공통 내비게이션의 최대 6개 계약을 위반했다.
2. 고정 좌표 버튼과 비율 좌표 버튼이 함께 사용되어 16:9와 20:9 모두에서 겹침이 발생했다.
3. 일부 버튼이 다른 버튼 뒤에 가려져 제작·모집·레이드·왕국 보고 기능에 안정적으로 접근할 수 없었다.
4. 튜토리얼은 실제 행동을 확인하지 않고 완료 명령만 실행해 핵심 게임 과정과 분리되어 있었다.
5. 내부 식별자·상태 코드·영문 장식 문구가 사용자 화면에 그대로 노출되었다.
6. 여러 전체 화면을 순서대로 열 때 이전 화면을 닫는 공통 규칙이 없었다.

## 3. 확정 내비게이션

하단 공통 내비게이션은 다음 6개만 노출한다.

| 순서 | 항목 | 역할 |
|---:|---|---|
| 1 | 왕국 | 시설 건설·상점·왕국 상태 |
| 2 | 용병 | 보유 용병·상세 상태 |
| 3 | 제작 | 시설 생산·재고 목표 |
| 4 | 지역 | 지역 허가·사냥 파견·해금 상태 |
| 5 | 모집 | 선술집 모집·특별 모집 |
| 6 | 메뉴 | 장비 공방·승급 심사·레이드·왕국 보고 |

하단 버튼은 안전 영역 너비를 6등분하고 동일한 간격과 높이를 사용한다. 화면 비율이 바뀌어도 버튼 수·순서·간격은 변하지 않는다. 보조 기능은 하단에 추가하지 않고 메뉴 패널에만 추가한다.

## 4. 화면 전환 계약

- 전체 화면은 한 번에 하나만 활성화한다.
- 다른 전체 화면을 열면 기존 화면과 메뉴 패널을 먼저 닫는다.
- 왕국 또는 용병 장면으로 이동할 때 열려 있던 전체 화면을 닫는다.
- 닫기 후에는 공통 하단 내비게이션으로 항상 복귀할 수 있어야 한다.

## 5. 실제 플레이 연결 계약

왕국 여정은 버튼 클릭으로 완료되지 않는다. `해당 기능으로 이동`은 목표 화면만 열고, 다음 실제 저장 상태가 확인된 경우에만 완료 처리한다.

| 단계 | 완료 근거 |
|---:|---|
| 1 | 왕국 화면 방문 기록 |
| 2 | 모집 이력 생성 |
| 3 | 대상 지역 허가 변경 사건 |
| 4 | 대상 지역 사냥 진행 또는 정산 사건 |
| 5 | 상점 판매 거래 원장 |
| 6 | 지정 무기 제작 결과가 상점 재고에 존재 |
| 7 | 지정 무기 구매 후 용병 장착 상태 |
| 8 | 지정 회복 물약 제작 결과가 상점 재고에 존재 |
| 9 | 정규 용병 승급 상태 |
| 10 | 두 번째 지역 해금 상태 |

왕국 보고를 열 때 저장 상태를 다시 평가한다. 충족되지 않은 목표를 완료 명령으로 강제로 넘길 수 없으며, 건너뛰기는 기존의 명시적 보조 기능으로만 유지한다.

## 6. 한국어 전용 표시 계약

- 사용자에게 보이는 제목·버튼·상태·오류·단위·등급·지역·직업·장비 이름은 한국어로 표시한다.
- 영문 내부 식별자, 결과 코드, 콘텐츠 버전, 저장 버전은 개발 로그와 테스트에서만 사용한다.
- 등급·단계·시간 단위도 한국어 표현을 사용한다.
- 텍스트 마크업 속성은 렌더링 제어 정보이므로 검사 대상에서 제외하되 화면에 문자로 노출되면 실패다.

## 7. 검증 기준

- 1920×1080, 2400×1080에서 활성 하단 버튼이 정확히 6개다.
- 활성 하단 버튼끼리 교차하지 않고 각 터치 영역이 64×64 이상이다.
- 여섯 기본 항목과 메뉴의 네 보조 항목으로 P04~P15 주요 화면에 모두 접근할 수 있다.
- 전체 화면을 연속으로 열어도 활성 전체 화면은 하나다.
- 충족되지 않은 튜토리얼 완료 명령은 거부된다.
- 실제 저장 상태를 만든 뒤 왕국 보고를 열면 해당 목표가 자동 반영된다.
- 실행 중 사용자 화면에 영문 식별자나 결과 코드가 노출되지 않는다.
- 편집 모드·플레이 모드 테스트, 안드로이드 빌드, 실제 실행 화면 검증이 모두 성공한다.

## 8. P16 진입 조건

위 검증 기준을 모두 통과하고 결함 목록에 심각도 높음 또는 보통 항목이 남지 않은 경우에만 P16 디자인·에셋 적용을 시작한다.
