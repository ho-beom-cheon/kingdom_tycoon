# 상시 사냥 자동 성장 루프 최종 설계서 v1.0

## 1. 목표

사냥터에 배치된 각 용병이 독립적으로 사냥하고, 귀환 뒤 전리품 판매·치료·소모품 구매·스킬 훈련·장비 강화를 수행한 다음 같은 사냥터로 복귀한다. 사용자는 출정을 반복 지시하지 않고 성장 결과와 정책만 관리한다.

## 2. 확정 사용자 흐름

`사냥터 배치 → 이동 → 탐색 → 전투 → 전리품 수집 → 귀환 판단 → 마을 귀환 → 판매 → 치료 → 구매 → 스킬 훈련 → 장비 강화 → 기존 사냥터 복귀`

- 같은 사냥터에 여러 용병을 배치할 수 있다.
- 각 용병의 상태·체력·가방·수익·성장은 서로 독립적이다.
- 회수 명령을 받지 않은 용병은 정비가 끝나면 자동 복귀한다.
- 자원 부족이나 성장 대상 부재는 사냥 루프를 중단시키지 않는다.

## 3. 스킬 자동 훈련 계약

- `job_skill_unlocks.csv`와 `mercenary_ranks.csv`를 정본으로 사용한다.
- 현재 직업과 등급에서 해금된 스킬만 대상이다.
- 스킬 레벨이 가장 낮은 항목, 그다음 슬롯 번호가 낮은 항목을 우선한다.
- 자동 훈련 최대 레벨은 3이다.
- 목표 레벨별 개인 골드 비용은 1레벨 50, 2레벨 150, 3레벨 400이다.
- 개인 골드 50은 귀환 후 최소 비축액으로 남긴다.
- 습득 스킬 레벨 합계는 사냥 피해 감소와 판매 수익 보너스에 반영한다.
- 훈련 결과는 Save의 `skillGrowth`에 영속화한다.

## 4. 장비 자동 강화 계약

- P10 `enhancement_rules.csv`의 재료·골드·성공 확률·실패 보호를 그대로 사용한다.
- 용병 자신이 장착한 장비 가운데 강화 수치가 가장 낮은 장비를 우선한다.
- 자동 강화는 안전 구간인 +5까지만 허용한다. +6 이상은 사용자 정책이 추가되기 전까지 자동 시도하지 않는다.
- 자동 정비는 해당 용병이 마을에 있을 때만 실행하며, 이 경우 장착 장비도 강화할 수 있다.
- 성공과 실패 모두 재료·골드·시도 횟수에 원자적으로 반영한다.
- P10 계약대로 실패 시 장비 파괴와 강화 단계 하락은 없다.

## 5. Save 계약

기존 `saveVersion=1`, `contentVersion=1.0.0-content.13`을 유지하고 다음 필드를 선택 필드로 추가한다. 기존 Save는 로드 시 기본값으로 정규화한 뒤 즉시 유효한 문서로 저장할 수 있어야 한다.

- 용병 `skillGrowth`: 규칙 버전, 스킬별 레벨·누적 사용 골드·최근 훈련 시각, 총 사용 골드
- 용병 `autonomy`: 자동 성장 사용 여부, 자동 스킬/강화 사용 여부, 골드 비축액, 최근 성장 행동·결과·시각
- 새 런타임 상태: `TRAIN_SKILLS`, `ENHANCE_EQUIPMENT`

## 6. 표시 계약

- 사냥터 명단에서 스킬 총 레벨과 최고 장비 강화 수치를 동시에 보여준다.
- 훈련·강화 상태와 최근 결과를 한국어로 표시한다.
- 1920×1080 기준, 16:9~20:9 Safe Area에서 명단과 현장 패널이 겹치지 않아야 한다.
- 성장 실패·자원 부족은 경고가 아니라 정상 정책 결과로 표현한다.

## 7. 원자성·복구 계약

- 한 용병의 한 상태 전이는 단일 Save revision에서 처리한다.
- 저장 충돌이나 스키마 실패 시 메모리 스냅샷도 갱신하지 않는다.
- 기존 Save 정규화는 멱등이어야 한다.
- 오프라인 따라잡기는 최대 180회 상태 전이로 제한하며 용병별 순서를 고정한다.

## 8. 완료 조건

1. 여러 용병이 같은 사냥터에서 독립적으로 순환한다.
2. 한 번 이상 귀환한 용병이 조건에 따라 스킬을 배우거나 장비를 강화한다.
3. 성장 결과가 Save 재로드 후 유지된다.
4. 골드·재료 부족이어도 같은 사냥터로 자동 복귀한다.
5. UI에 한국어 상태와 성장 수치가 표시된다.
6. EditMode·PlayMode·전체 CI가 통과한다.
