# 지역·몬스터·레이드

## 지역 개방과 출입 분리

- 지역 개방: 왕국 계정 단위
- 출입 자격: 용병 개인 성장 랭크

둘 다 충족해야 한다.

## 1.0 지역

1. 왕국 외곽 초원 — 수습
2. 어둠숲 — 정식
3. 버려진 광산 — 숙련
4. 독안개 늪지 — 정예
5. 얼어붙은 유적 — 영웅

## 개방 유형

- 왕국 단계
- 특정 정예 몬스터 처치
- 시설 조건
- 레이드 최초 성공

## 레이드

1. 역병 히드라
   - 늪지 진행의 결산
   - 최초 토벌로 얼어붙은 유적 개방
   - 독·치유·부위 파괴 학습

2. 잿빛 고룡
   - 왕국 완성 후 최종 레이드
   - 최초 토벌은 1차 엔딩
   - 반복 난이도와 변종 개방

## 레이드 준비

- 6~8명 편성
- 랭크 제한
- 포션 준비
- 역할 경고
- 공격 부위 목표
- 예상 보상

## 부위 파괴

보스 재료는 부위에 연결한다.

- 뿔: 무기
- 비늘·몸통: 방어구
- 날개: 속도·회피
- 심장: 마법·유물

같은 보스를 반복하더라도 제작 목표에 따라 공략 부위를 바꾼다.

## 실패

- 영구 사망 없음
- 부상 시간
- 소지품 일부 손실은 1.0 기본 비활성
- 포션 소비는 유지
- 재도전 가능
