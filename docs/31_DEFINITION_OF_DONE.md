# 1.0 완료 정의

## 게임

- 새 게임부터 최종 레이드까지 진행 가능
- 핵심 루프가 수동 치트 없이 연결
- 5직업·5지역·2레이드 동작
- 8시설과 4관리 NPC 동작
- C~SS, 수습~전설 동작
- 제작·강화·제련·분해 동작
- 주점·특별 모집 Mock/Server Adapter 동작

## 안정성

- 신규 저장·로드
- 백업 복구
- Save Migration
- 오프라인 정산
- 앱 강제 종료 복구
- 재화 음수·복제 없음

## UI

- 주요 화면 6상태
- Safe Area
- 한글 잘림 없음
- 뒤로가기·모달 규칙
- 접근성 설정
- 사용자 노출 화면에 디버그용 도형·문구·누락 에셋 없음
- 왕국·용병·제작·지역·모집·메뉴의 색상·간격·아이콘·Drawer 규칙 일치
- 시설 성장·용병 행동·희귀 보상을 형태·색상·모션으로 식별 가능

## 성능

- 최대 활동 용병·몬스터에서 목표 프레임
- 메모리 지속 증가 없음
- 주요 목록 스크롤 가능

## 개발

- 테스트 통과
- 콘텐츠 검증 통과
- 모든 외부 에셋의 라이선스 등록과 상업 이용·수정·크레딧 조건 확인
