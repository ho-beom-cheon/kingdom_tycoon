## 1. 구현 결과

기존의 하단 탭과 사냥터 화면 전환 중심 구조를 중앙 왕국과 사방 사냥터가 한 공간에 존재하는 모바일 우선 통합 월드로 교체했다.

- 기준 해상도 1080×1920, 연속 월드 3000×4200
- 중앙 왕국과 주점·상점·대장간·치료소·모험가 길드 배치
- 북·동·남·서 사냥터와 북쪽 외곽 고등급 사냥터 배치
- 가로·세로 드래그, 관성, 0.65~1.35배 확대·축소, 경계 클램프, 드래그 후 탭 오작동 억제
- 왕국 대기·시설 이동·상점 거래·장비 강화·치료·사냥터 이동·전투·귀환 상태에 따른 용병 월드 이동
- 5개 사냥터에 총 25개 몬스터와 HP·피격·보상 피드백 유지
- 사냥터를 누르면 하단 배치 시트가 열리고 여러 용병을 같은 사냥터에 계속 배치 가능
- 기존 하단 기본 내비게이션을 숨기고 우측 상단 `왕국`·`소식`·`메뉴`로 통합
- 통합 메뉴에서 용병·가방·장비·스킬·상점·대장간·주점·길드·레이드·설정을 한국어로 제공
- 세로형 긴 화면과 가로형 폴백에서 Safe Area·64px 터치 영역·무겹침 계약 유지

## 2. 무료 에셋과 교체 경계

Pixel-boy의 공식 `Ninja Adventure - Asset Pack` 저장소에서 CC0 환경 PNG 5개만 선별 반입했다.

- 출처 페이지: `https://pixel-boy.itch.io/ninja-adventure-asset-pack`
- 공식 저장소: `https://github.com/pixel-boy/NinjaAdventure`
- 확인 리비전: `6ac78232d5aedcc85ce5f27d060ea92366f7c24a`
- 라이선스: `CC0-1.0`
- 등록 ID: `ASSET_CC0_NINJA_ADVENTURE_ENVIRONMENT`
- 반입 파일: 바닥 타일 1개, 버려진 마을 타일 1개, 풀 1개, 상자 1개, 항아리 1개
- 적용 규칙: `Point` 필터, `Clamp` 래핑, 런타임 부분 크롭과 캐시

캐릭터·몬스터·음악·폰트·Godot 스크립트는 반입하지 않았다. 기존 내부 픽셀 라이브러리는 용병·몬스터 표현과 외부 텍스처 누락 시 폴백으로 유지했다. 추가 지출은 0원이며 출처·라이선스·상업 이용·수정 허용 여부는 `THIRD_PARTY_NOTICES.md`와 `data/csv/asset_register.csv`에 기록했다.

## 3. 기존 계약 영향

- Save content 버전 `content.13`, JSON Schema, 마이그레이션, 체크섬을 변경하지 않았다.
- 전투·전리품·판매·자동 구매·성장·서버 API 판정 로직을 변경하지 않았다.
- 기존 지역 화면의 내부 계층은 호환 목적으로 유지하되, 사용자 진입점은 통합 월드로 연결했다.
- 왕국 첫 화면은 통합 월드를 자동으로 열고 관리 화면 진입 시 기존 서비스 화면을 재사용한다.
- 런타임 외부 텍스처가 없거나 로드에 실패해도 내부 색상·픽셀 폴백으로 플레이가 계속된다.
