# P17 설계 완결성 검토

## 판정

**구현 가능 (`PASS`)**

`TYCOON_P17_BALANCE_OPTIMIZATION_RC_COMPLETE_DESIGN_v1.0.md`는 P17 구현을 시작하기 위한 범위, 수치 기준, 자산·라이선스 결정, 호환성, 검증, RC 빌드와 롤백 계약을 확정했다. 구현을 막는 `UNRESOLVED`는 없다.

## 저장소 차이와 구현 목록

1. P15 캡처에 영문 머리말과 내부 ID가 노출돼 한국어 전용 기준을 위반한다.
2. 시설과 전투 자산 일부가 단순 단색 도형이라 출시 후보의 시각 밀도에 부족하다.
3. 기존 Android 빌드는 Development이며 P16 APK가 약 76.4MB로 증가했다.
4. P16 빌드 로그에 TMP Font Asset 누락과 Android Localization App Info 경고가 있다.
5. P17 전용 밸런스·성능·라이선스·한국어·레이아웃 게이트가 없다.
6. 실제 Android 기기 10분 프로파일링은 로컬 자동화 범위 밖이며 RC 생성 후 수동 승인 대상으로 남는다.

## 결정 기록

- 상용화: RC 결과 확인 후 조건부 진행
- 유료 에셋: 미도입
- 사용자 구매 승인: 없음
- 실제 집행액: 0원
- 외부 에셋: 추가 없음
- 생성형 외부 서비스: 사용하지 않음
- P17 콘텐츠/Save/DB/API migration: 없음

## 구현 진입 조건

설계의 자동 게이트와 RC 설정을 그대로 구현한다. 밸런스 데이터 자체가 목표를 벗어나 콘텐츠 수정이 필요한 경우에만 새 콘텐츠 버전 설계가 필요하므로, 그때 하나의 통합 `UNRESOLVED`로 중단한다. 그 외 발견되는 UI, 문자열, 글꼴, 자산, 테스트, 빌드 문제는 P17 범위에서 반복 수정한다.
