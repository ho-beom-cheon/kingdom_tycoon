# 상시 사냥 자동 성장 구현 증적

## 구현 결과

- 용병별 상시 사냥 귀환 흐름에 `스킬 훈련 → 장비 강화 → 기존 사냥터 복귀`를 연결했다.
- 활성 콘텐츠의 직업·등급별 스킬 해금표와 P10 강화 규칙을 런타임에서 직접 사용한다.
- 스킬 성장에 따른 피해 감소·판매 수익 증가를 실제 사냥 계산에 반영한다.
- 안전 구간 +5까지 장착 중인 자기 장비를 자동 강화하며, 자원 부족은 사냥을 막지 않는다.
- 기존 content.13 Save는 선택 필드를 멱등 정규화하고 `saveVersion=1`을 유지한다.
- 사냥터 명단과 상태 표시를 한국어로 유지하며 스킬 총 레벨과 최고 강화 수치를 노출한다.

## 핵심 회귀 시나리오

1. 이전 Save에서 새 필드를 제거해도 정규화 후 스키마 저장에 성공한다.
2. 같은 사냥터의 여러 용병이 서로 다른 상태와 성장 기록을 유지한다.
3. 귀환 용병이 해금된 스킬을 구매하고 개인 골드 비축액을 보존한다.
4. 장착 장비와 강화석을 가진 용병이 +1 강화 후 같은 사냥터로 복귀한다.
5. 16:9 및 20:9 화면에서 활성 버튼이 겹치지 않고 64×64 최소 터치 영역을 지킨다.
