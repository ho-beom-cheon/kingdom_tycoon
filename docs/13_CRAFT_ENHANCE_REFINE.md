# 제작·강화·제련

## 제작

```text
재료 확보
→ 창고 입고
→ 제작법·시설·NPC 조건 확인
→ 생산 큐
→ 품질 판정
→ 상점 진열 또는 보관
```

플레이어는 목표 재고와 우선순위를 설정한다. NPC가 자동 생산한다.

## 강화

- +1~+5: 100% 성공
- +6~+10: 확률 적용
- 실패 시 장비 파괴·단계 하락 없음
- 실패 누적 보정
- 강화석은 장비 분해와 보스 콘텐츠에서 획득
- 분해 시 투자 강화 재료의 기준 70%를 환급(TUNABLE)

## 제련

- 장비당 1개 옵션
- 옵션군: 공격/방어/수집/속성/보스
- 몬스터 특수 재료 사용
- 현재 옵션과 새 옵션 중 선택 가능
- 선택하지 않아도 재료는 소모
- 옵션 잠금·다중 옵션은 DEFERRED

## 제작 품질

다음의 조합으로 판정:

- 장비 기본 품질 가중치
- NPC 숙련
- 시설 레벨
- 희귀 보조 재료
- 제작법 숙련

유료 재화로 품질을 직접 확정하지 않는다.
