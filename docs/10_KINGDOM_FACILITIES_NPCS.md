# 왕국·시설·NPC

## 왕국 단계

1. 폐허 전초기지: 활동 4
2. 정착 마을: 활동 8
3. 요새 도시: 활동 12
4. 성채 수도: 활동 16
5. 복구된 왕국: 최종 레이드 개방

## 핵심 시설 8종

1. 주점: C~A 모집
2. 용병 숙소: 활동·보유 슬롯
3. 모험가 길드: 승급, 레이드 접수, 출입 자격
4. 상점: 재료·장비 매입, 상품 판매
5. 대장간: 장비 제작, 강화, 기본 제련, 분해
6. 연금술 공방: 포션 제작
7. 창고: 재료·상품 보관
8. 치료소: 부상·상태 이상 치료

1.0에서는 제련소, 분해소, 레이드 본부를 별도 건물로 나누지 않는다.

## 개방

```text
조건 달성
→ 시설 건설 권한 + NPC 고용 후보 동시 개방
→ 시설 건설
→ NPC 고용·배치
→ 가동
```

초반 핵심 시설은 튜토리얼 지급 NPC를 사용할 수 있다.

## 관리 NPC

- 상점 주인
- 대장장이
- 연금술사
- 치료사

숙련도:

```text
견습 → 숙련 → 장인 → 명장
```

작업 처리량과 작업 난이도로 숙련 XP를 얻는다.

## 시설과 NPC의 역할 분리

- 시설 레벨: 큐, 저장량, 처리 속도, 기능 범위
- NPC 숙련: 품질, 재료 효율, 제작법 사용 자격
- 제작법: 상품 종류
- 재료: 실제 생산 가능 여부

## 시스템 NPC

직접 육성하지 않는다.

- 주점 등록관
- 길드 심사관
- 레이드 접수원
- 특별 모집 담당자
- 떠돌이 상인
