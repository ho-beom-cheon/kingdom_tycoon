# 위험과 축소 순서

## 주요 위험

1. 자율 AI가 자연스럽지 않음
2. 경제가 멈추거나 인플레이션
3. 장비 자동 판단이 납득되지 않음
4. 무료 에셋 스타일 불일치
5. Unity UI 정보 과밀
6. 서버 범위를 너무 일찍 확대
7. 데이터·Save 마이그레이션 누락

## 일정 압박 시 축소

1. 레이드 2개 중 최종 레이드 콘텐츠 수를 줄이되 구조 유지
2. 몬스터 변형 수 축소
3. 장비 외형 반영 범위 축소
4. 특별 모집은 Mock UI까지만, 서버 엔드포인트 최소화
5. 도감 보상 단순화
6. 오프라인 희귀 드롭 제한

## 절대 제거하지 않음

- 자율 사냥
- 판매·구매 경제
- 장비 획득·자동 착용
- 포션 생산
- 승급
- 지역 출입
- 최소 1개 레이드
- 저장
