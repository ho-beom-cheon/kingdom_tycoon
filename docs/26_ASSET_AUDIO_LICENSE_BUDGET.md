# 에셋·음향·라이선스·예산

## 예산

- 유료 에셋 총합 최대 200,000원
- 버티컬 슬라이스 전 구매 금지
- 무료 에셋 80~90% 목표
- 구매는 1개씩, 약점 검증 후 진행

## 우선순위

1. 통일된 환경·건물
2. 아이템·재료 아이콘
3. 캐릭터·몬스터 보완
4. 효과음·BGM
5. 소형 VFX

## 구매하지 않음

- 완성형 RPG 프레임워크
- 범용 유료 Save 시스템
- 고가 AI 도구
- 여러 스타일의 중복 타일팩

## 라이선스 등록

`asset_register.csv`에 기록:

- 이름
- 제작자
- URL
- 버전
- 취득일
- 가격
- 라이선스
- 상업 사용
- 수정 허용
- 크레딧 의무
- 사용 위치

## 아트 기준

- 타일 기준 목표 32×32
- 4방향 캐릭터
- 월드 Point Filtering
- UI 고해상도
- 장비 무기·투구·주요 색상 반영
- 서로 다른 PPU·외곽선·광원 방향을 무분별하게 섞지 않음

## 음향 이벤트

- 구매·판매
- 제작 완료
- 희귀 드롭
- 강화 성공·실패
- 제련
- 승급
- 지역 개방
- 레이드 경고·클리어

일상 행동은 절제하고 중요한 보상만 강하게 연출한다.
