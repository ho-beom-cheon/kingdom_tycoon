# 에셋·음향·라이선스·예산

## 예산

- P08~P16은 상업 이용이 확인된 무료·기보유 에셋을 우선한다.
- 무료 에셋 80~90% 목표
- P17 초입에 게임 완성도, Android 실기기 결과, 전체 UX와 상용화 의사를
  함께 검토한다.
- 상용화 결정과 사용자 명시 승인이 모두 있기 전에는 유료 에셋을 구매·도입하지
  않는다.
- 승인된 유료 에셋 총합은 최대 200,000원이며, 한도는 집행 승인이 아니다.
- 구매는 실제 완성 화면에서 확인된 약점을 해결하는 항목만 1개씩 진행한다.

## 단계별 적용

1. P08~P14: 무료·기보유 에셋으로 기능별 화면을 만들고 스타일 편차를 기록한다.
2. P15: 전체 화면 흐름, 공통 UI, 색상, 폰트, 피드백과 무료 에셋을 통합한다.
3. P17 초입: 상용화 여부와 에셋 격차 목록을 확정한다.
4. 상용화 승인 시에만 환경·건물, 캐릭터·몬스터, 아이콘, 음향, VFX 순으로
   선택 구매·교체하고 RC를 다시 검증한다.

구매하지 않기로 결정해도 무료 에셋 기준으로 P17 QA와 RC 후보 생성은 계속할
수 있어야 한다.

## 우선순위

1. 통일된 환경·건물
2. 아이템·재료 아이콘
3. 캐릭터·몬스터 보완
4. 효과음·BGM
5. 소형 VFX

## 구매하지 않음

- 완성형 RPG 프레임워크
- 범용 유료 Save 시스템
- 고가 AI 도구
- 여러 스타일의 중복 타일팩

## 라이선스 등록

외부 에셋은 프로젝트에 넣기 전에 `asset_register.csv`에 기록한다.

- 이름
- 제작자
- URL
- 버전
- 취득일
- 가격
- 라이선스
- 상업 사용
- 수정 허용
- 크레딧 의무
- 사용 위치

외부 게임의 스크린샷·추출 이미지·음원·UI를 런타임 에셋으로 사용하지 않는다.
무료 표기만으로 상업 이용 가능하다고 추정하지 않고 개별 라이선스 원문을
확인한다.

## 아트 기준

- 타일 기준 목표 32×32
- 4방향 캐릭터
- 월드 Point Filtering
- UI 고해상도
- 장비 무기·투구·주요 색상 반영
- 서로 다른 PPU·외곽선·광원 방향을 무분별하게 섞지 않음
- Sprite·Audio 참조는 ID·카탈로그를 통해 교체 가능하게 유지

## 음향 이벤트

- 구매·판매
- 제작 완료
- 희귀 드롭
- 강화 성공·실패
- 제련
- 승급
- 지역 개방
- 레이드 경고·클리어

일상 행동은 절제하고 중요한 보상만 강하게 연출한다.
